Privacy Policy

Last updated: 1 November 2026

This policy covers the "Agent Shipped" application (the "App"), a publishing tool that the owner of the Agent Shipped YouTube channel uses to upload videos and read analytics for that channel. It also covers this website.

Who uses the App

Only the channel owner. The App is not offered to the public and has no user accounts of its own.

Google user data

The App accesses the channel owner's Google account through the YouTube Data API and YouTube Analytics API with the following permissions: uploading and managing videos on the channel, and reading the channel's analytics. It uses this access only to publish videos to the Agent Shipped channel and to read that channel's performance data. It does not access any other Google account or any other person's data.

OAuth tokens are stored locally on the channel owner's own computer and are never shared with third parties. The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data from viewers

This website does not use cookies, analytics or tracking, and collects no personal data from visitors. Viewer data on YouTube is handled by YouTube under Google's privacy policy.

Sharing and retention

No data is sold or shared. Tokens can be revoked at any time at myaccount.google.com/permissions, which immediately ends the App's access.

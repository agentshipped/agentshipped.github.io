A Claude Code subagent finishes and hands back exactly 4 lines, and the last one names a case it skipped.
Demo repo (agentshipped/notes-api): https://github.com/agentshipped/notes-api
Full build: https://youtu.be/lSzonRoE2ok

The format is a fixed template in the agent definition: result, commit, tests, open items.
In the demo, the open items line named 1 skipped edge case (empty q not handled) on a search endpoint.
Not just JavaScript: any agent framework works the same way, with a fixed output template in the agent prompt and pytest instead of node --test.
Tools: Claude Code, subagents, node --test, git
Techniques from my real projects, shown on a public demo repo.

A fake server restart is caught by a counter that must go up by exactly one.
Demo repo (agentshipped/notes-api): https://github.com/agentshipped/notes-api
Full build: https://youtu.be/lSzonRoE2ok

One prompt adds a launch counter to the health endpoint and a script that restarts, re-reads, and checks the delta.
With the restart broken on purpose: delta no instead of 1, exit code 1, in one run.
Not just JavaScript: same idea with a Flask app and pytest, or a Go service and go test.
Tools: Claude Code, Node.js, Express, shell script
Techniques from my real projects, shown on a public demo repo.

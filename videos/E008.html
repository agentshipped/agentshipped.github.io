My PM agent wrote no code. My first gate blocked a legal write

E008 · Build log · 15 Nov 2026

Watch on YouTube · Demo repo (agent-starter) · Write-up with every command and prompt

A PM agent planned three tasks and wrote no code, and a PreToolUse hook blocked the one write I forced outside its scope.
Demo repo (agentshipped/agent-starter): https://github.com/agentshipped/agent-starter

The PM writes only the plan, and each task gets a disjoint file scope that the hook checks on every Edit, Write and MultiEdit.
My first version of the gate blocked a legal write because of absolute vs relative paths. You see the fix and the six tests.
You can copy the plan file, the disjoint scopes, the exit-2 hook and the four-line subagent hand-back. The gate does not watch Bash yet.
Not just JavaScript: write the gate in Python and test it with pytest, or enforce the same scope at commit time with a pre-commit hook.
Tools: Claude Code, PreToolUse hooks, subagents, Node.js (node --test), git

My .gitignore silently ate the folder my agent was about to fill #Shorts

E021 · Short · 26 Nov 2026

Watch on YouTube · Demo repo (agent-starter)

I checked my own .gitignore with git check-ignore before the agent wrote any code, and it flagged both planned tools/ files.
Demo repo (agentshipped/agent-starter): https://github.com/agentshipped/agent-starter

The fix was to move the files to bin/, not loosen the rule. Both then showed up as untracked.
Not just JavaScript: git check-ignore works in any stack. In Python, run it on planned paths before a pytest or build output folder swallows them.
Tools: git, git check-ignore, git status, Claude Code
